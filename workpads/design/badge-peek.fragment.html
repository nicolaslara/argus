Badge-Peek

best for: a dense, stable run overview you drill on demand. The plan DAG stays compact — a fanned step never grows; it wears a status-count badge cluster (●3 ◌2 ✕1) and the verify step is an accent diamond. Click/hover a step → an ephemeral peek lists its instances (label · status · duration); each row opens the DetailPanel. Stance: ONE run view (plan-shaped) + a throwaway popover — the badge answers "how many / which states" at a glance, the peek answers "which ones," the panel answers "everything about one." Plan stays its own separate view. Loop-until-done: the back-edge re-enters the same compact node; its badge just re-counts per pass (×pass shown in the peek footer) — the node never multiplies. Tournament: each round is one fanned step whose badge reads survivors (e.g. ●4 ✕4); the peek lists winners↑ / eliminated↓ without widening the bracket. Shown mid-run: REVIEW is the live decision gate (correctness+security ◌ running, feasibility ✕ failed) with its peek open, so SYNTHESIZE is still a dashed ghost.
