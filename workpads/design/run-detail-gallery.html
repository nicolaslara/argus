Inline-expand instances

best for: scanning every subagent at once, then opening any one in place — no panel, no tab, never leave the lane. The fan-out drawer renders all its instance cards EXPANDED by default in a grid: each card carries label · status dot · dur · tokens · a one-line result/prompt preview. A small open ▸ on any card expands THAT card inline to reveal the full verbatim prompt (monospace, collapsible) and the readable StructuredOutput result (with a raw-JSON toggle) right beneath it, pushing the grid down — so you compare siblings at a glance and dive into one without losing the others. Tradeoff: rich in-lane cards cost vertical space, so a wide fan (×8+) wants the lane scrollable; the right-side DetailPanel is still one click away for the full timeline.

Run-selector drawer

best for: a Run view that defaults to the latest run but can move to any other — with success / fail / in-progress legible at a glance, without leaving the view. Tradeoff: a dropdown keeps the chrome compact and the history one click away, but unlike an always-on run rail it hides older runs until opened — so trend/cadence ("3 of the last 5 failed") isn't visible until you pull the drawer. Chosen because the Run view is about one run at a time; the picker is navigation, not a dashboard.
